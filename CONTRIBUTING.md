# Contributing

Contributions are welcome through issues and pull requests.

## Local checks

```console
moon fmt
moon check
moon test
moon info
```

New behavior should include a focused test. If behavior comes from a standard
or another implementation, include the source link and confirm its license is
compatible with Apache-2.0.

## Commit history

Keep changes small enough to review and use a descriptive commit message. This
repository preserves development history because reproducibility and ongoing
maintenance are part of the project goals.
